# Console Todo application project

## 📌 Description

The Task Management Application is a simple yet effective project designed to help students practice Object-Oriented Programming (OOP) principles while building a real-world task management system. This application allows users to create, update, complete, and remove different types of tasks, such as simple tasks, recurring tasks, and deadline-based tasks. Additionally, it provides reporting features to track productivity and task completion rates.

Through this project, students will learn by doing, encountering real-world coding challenges that highlight the importance of SOLID principles, design patterns, and maintainable code structures.

## 🎯 Objectives

- **Understand the Importance of SOLID Principles 🛠️**
  Identify design flaws, apply SOLID principles, and improve modularity with dependency injection.

- **Practice OOP Concepts 🛠️**
  Apply OOP and SOLID principles to build a scalable and flexible task management system.

- **Enforce Thoughtful Design Decisions 🧠**
  Document design decisions, justify choices, and analyze trade-offs of available solutions.

- **Gain Hands-on Experience with Git & GitHub 🌍**
  Use GitHub for version control, practice Git operations, and develop collaboration skills for real-world teamwork.

By working through this project, students will develop a deeper understanding of software design, version control, and collaborative coding, ensuring they are ready for professional software development.
