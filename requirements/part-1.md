# 📄 Task Management - Part 1

## Tasks

User can manage different types of tasks such as (**Simple**, **Recurring**, **Deadline**, etc.) Maybe we will have another type in the future 🙂.

1.  Create task of different types.
2.  Set completion status
3.  Update task information such as title, description, date, etc.
4.  Remove the task.
5.  List all tasks sorted by it's priority and show status and type of each task.

---

# Reporting

User can use your application to print a report of the following:

1. Count of completed tasks (of any type).
2. Count of uncompleted tasks.
3. Productivity ratio [completed / All].
4. Top 3 Most Common Task Types.

## Notes

1. Each task has its `priority`, so when the user asks to list all open tasks, the tasks should be sorted based on their priority.
2. You can store tasks wherever you want: `in-memory`, `database`, `file`, etc. **but** maybe we will need to change it in the future.
3. Design document should have your ideas and opinions, it's important to show how you are thinking and why you choose this approach.
